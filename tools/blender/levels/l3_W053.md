# W-053 — Downtown Rot Row art kit

49 exported models cover the new L3 art inventory in `docs/levels/L3-rotrow.md`
sections 4, 10 and 11. The kit contains **41,277 triangles / 1,699,116 GLB bytes**.
Each model meets its individual budget. `public/assets/manifest.rotrow.json` is
the level-specific manifest approved in D-042; the shared L2 manifest is untouched.

The builds and checks below were run on Windows with Blender **5.2.3 LTS**
(`e13b728c6880`), Node 24.17.0 and Three 0.180.0. Source baseline is
`d6234c2722119cab442811d57ae6dccc191cc09f`; the preceding claim commit is
`18a34c20577f7902862d0e0252d4877c6ea0b354`. Model and manifest SHA-256 identities
are retained in `l3_evidence/runtime-audit.json` and the manifest. Evidence concerns
the W-053 changes on that baseline, not later upstream changes.

## Reproduce

From the repository root after `npm ci`, with Blender 5.2.3 and Python/Pillow:

```powershell
blender --background --threads 4 --python-exit-code 1 --python tools/blender/levels/build_rotrow.py -- --preview
blender --background --threads 4 --python-exit-code 1 --python tools/blender/levels/build_rotrow.py -- --verify
node tools/blender/levels/l3_check_runtime.mjs
python tools/blender/levels/l3_cli_guards.py --blender blender
python tools/blender/levels/l3_preview_sheets.py
npm run typecheck
npm test -- tests/unit/levels-assets
npm run verify:assets
```

Use the Blender executable's full path when it is not on PATH. `--out DIR`
builds a private candidate; `--only id,id` selects a batch. No Meshy account or
credits are needed to rebuild: the generated source is retained and hash-checked.
The driver validates the entire requested batch before publishing; each file is
replaced and the manifest is written last. This is not an atomic transaction
across all 49 files. An interrupted publication requires a successful rerun or
restore before serving the kit. Failed pre-publication checks leave assets intact.

## Meshy source and selection

The owner explicitly authorized credit use. A single jukebox generation and
texture stage succeeded for **15 credits total** (5 + 10); no paid retries.
The task IDs, prompts, source GLBs, previews and sanitized hashes are retained in
`l3_meshy/`. Signed download metadata stays local and ignored.

`l3_meshy_jukebox.py` maps the generated colour regions to the game's existing
flat materials, normalizes height to 1.65 m and adds geometric speaker bars and
controls. The final exported variant is **1,781 / 1,800 triangles**, with Paint
recolouring, vertex AO, and a separate emissive glow node. It contains no images
or UV textures. The sculpted arch and skull details improve its silhouette over
the initial authored candidate. Full 2K textured source remains available for
other projects. Original authored mesh and recipe are preserved in
`l3_meshy/PARKED.md`; the lead can add this record to the shared PARKED file.

No Sketchfab asset was imported. The other 48 assets use authored procedural
geometry. The three carry items have named grip nodes; imported home objects
were not duplicated.

## Runtime handoff to Claude Cloud

- Register the manifest and corresponding object/variant IDs in the L3 runtime
  lane. These files supply the art; they do not implement a playable L3 area.
- The manifest's `footprint` is the existing level-kit tile width/depth convention,
  not the newer W-073 convex `outline` contract. Collision outlines and placement
  integration remain coordinated with that owner; no invented collision claims.
- Part names, contact nodes and `extras` identify door, bag, DJ platter, neon,
  screen, bulb, frost and water controls. The loader audit exercises actual door,
  bag and platter transforms; gameplay triggers remain runtime-owned.
- `ball_mirrorSkull` has a `ceiling_mount` attachment marker; its local origin is
  normalized for asset inspection, not a claim of automatic ceiling placement.
- Exterior building backdrops have no furnished interiors. The dance floor is a
  visual tile; general floor-style shader integration is renderer-owned.
- Brand/ad-panel nodes support later Terra artwork. Current lettering is original
  house signage; no replacement of Terra-owned logo files.

## Visual corrections retained in the final build

The fridge has an open cabinet cavity behind its glass door, shelves and bottles;
the grocery shelf is stocked on both sides. Counter stools clear the apron,
the flower display has leaves, the fish price board has support posts, and the
neon text fits its panel. Strict-budget violations were corrected before publish,
without raising budgets. Rendered sheets show exported bytes, not authoring-only
scenes. Grey capsules and checker floors are preview references, not game meshes.
