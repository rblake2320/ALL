## Reproduce

Run `npm ci`, then from the repository root, with Blender 5.2.3 and Python/Pillow:

```powershell
python tools/blender/levels/l5_verify.py --blender blender
```

Pass the full Blender executable path if it is not on PATH. This executes all
eleven acceptance steps, including a web build and audits of its actual GLBs.
No account, paid API or downloaded model is needed. For a private candidate:

```powershell
blender --background --threads 4 --python-exit-code 1 --python tools/blender/levels/l5_build.py -- --out tools/blender/out/mausoleum-candidate --preview --res 384 --samples 24
```

`--only id,id` selects a batch; `--verify` rebuilds and compares without repairing
published files. The Windows lock uses `msvcrt`; POSIX uses `fcntl`. The canonical
level build engine performs the export, AO, quantization and validation. The small
L5 wrapper supplies its inventory, separate manifest, lock and imported previews.
The per-kit lock wraps the actual publish entrypoint as well as verification,
and uses `common.publish_lock` after the upstream helper migration.
It refuses to prune unknown files and refuses malformed/unknown manifest entries.

The whole requested batch is validated before publication. Publication replaces
individual files and then the manifest; it is not one filesystem transaction
across all 28 files. After interruption during publication, rerun successfully
before serving the kit. Logs are normalised to LF before hashing so Git preserves
the exact receipt-bound bytes on both platforms.

## Art and runtime contract

- Coordinates use metres, glTF Y-up and +Z-front. `tileFootprint` is the authored
  tile allocation; dimensions/heights for the five store extras and roof reference
  kit are authored choices where the design has no numeric art table.
- No image textures, external buffers, skins or embedded animation clips. Colours
  and vertex AO follow the shared art pipeline; eight objects expose `Paint`.
- Named nodes expose flames, speaker/record, mirror door, water, mammoth head,
  vitrine glass and four display surfaces, replaceable canvas, flag, pendulum and
  the three roof subassemblies. The banquet table has six surface markers and
  eight separate chair contacts. `contact_*` nodes identify authoring positions;
  they do not implement interactions or prove actor clearance.
- The Mansard roof is a reference assembly for walls approximately 12 × 8 metres,
  with `roofBase=0`, `referenceSize` and `attachment` metadata. It is not a universal
  procedural roof solver. Environment mansions are exterior dressing.
- Reflecting pool and mirror have material surfaces. Dynamic reflected characters
  require renderer integration. The closed coffin has no visible contents.
- Generated collision `outline` and formal contact-frame integration belong with
  the shared D-043 helper/placement lane. No rectangular tile size is presented as
  an already tested collision polygon. The runtime owner must wire these assets,
  actor interactions and the full L5 lots/quests before calling L5 playable.

## Corrections and decisions

The first strict candidate rejected four triangle overruns and one floating lawn;
budgets were kept unchanged. Removing bevels from tiny book spines/quoin blocks
and reducing lace/canape tessellation corrected those overruns. A closed displaced
slab corrected the lawn's ground contact and coplanar flicker. The clock has an
open carved pendulum bay so the bob remains visible at game scale. Actual exported
geometry checks now cover the latter two defects. Failed candidate logs are
retained as failures, not relabelled as final acceptance.

All 28 models are original scripted geometry. Blender is appropriate here because
the design calls for exact dimensions, small budgets, repeatable builds and named
moving parts. No Meshy batch was needed, and no Sketchfab model was imported.
Reference research informs architectural/anatomical forms, not copied meshes:
[Pennsylvania Historical & Museum Commission: Second Empire](https://www.phmc.state.pa.us/Portal/Communities/Architecture/styles/second-empire.html),
[Florida Museum: Columbian Mammoth](https://www.floridamuseum.ufl.edu/100-years/object/columbian-mammoth-exhibit/).

Changelog line for Cloud at merge: "Added the 28-model Mausoleum Hills art kit,
reproducible Blender builds, exported-model visual sheets and source/built-asset
acceptance checks." No shared changelog, runtime or branding files were edited.

Grey scale capsules, walls and checker floors in the sheets are preview references,
not shipped meshes.
